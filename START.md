# Uruchomienie bez Terminala

1. Rozpakuj cały folder ZIP. **Nie przenoś samego `index.html` bez folderu `aplikacja`.**
2. Otwórz w Finderze `aplikacja/index.html` (dwuklik, Safari/Chrome).
3. W menu są etapy, pliki, kontrola wymagań oraz **09 Trening i planer ASD**.
4. W module 09 użyj `Wczytaj przykład kontrolny` — wynik powinien wynieść 66,7%. Oznacz B jako gotowe — 100%.
5. Eksportuj oddzielnie JSON postępu pracy, JSON kontroli wymogów oraz JSON modułu ASD. Dane i pliki w przeglądarce mogą zostać usunięte wraz z jej danymi.

Do uruchomienia strony nie jest potrzebny Node.js ani Internet. Jedynie do wykonania automatycznych testów należy zainstalować Node.js i uruchomić `npm test` w folderze projektu.
